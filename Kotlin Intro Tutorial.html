Kotlin Intro: разбор всех файлов section2

От hello world до generics — что, зачем и почему используется в каждом примере
01_hw.kt Hello World и аннотация @JvmName точка входа
Зачем: Первая программа, демонстрирующая минимальный синтаксис Kotlin: функция main и вывод строки. Аннотация @JvmName показывает, как управлять именем JVM-класса, который генерируется для файла.
// @file:JvmName("HelloWorld") — задаёт имя класса для всего файла @file:JvmName("HelloWorld") package section2 fun main() { print("Hello world!") }
  • @file:JvmName("HelloWorld") — по умолчанию Kotlin сгенерировал бы класс 01_hwKt, но аннотация даёт ему имя HelloWorld. Именно это имя используется в build.gradle.kts как mainClass.
  • fun main() — точка входа в программу. В Kotlin не нужны static или public.
  • print вместо println — вывод без перевода строки.
02_comments.kt Комментарии синтаксис
Зачем: Показать оба типа комментариев в Kotlin: однострочные // и многострочные /* */. Это базовый инструмент документирования и отладки.
package section2 // This is a single line comment /* This is a multi-line comment. */
  • Однострочные комментарии работают до конца строки.
  • Многострочные занимают несколько строк, но в Kotlin не вкладываются друг в друга.
  • Комментарии не влияют на работу программы — компилятор их игнорирует.
03_variables.kt Изменяемые и неизменяемые переменные var / val
Зачем: Объяснить разницу между var (изменяемая) и val (только для чтения). Показать правила именования и необходимость объявления до использования.
var age = 33 age = 30 // можно менять val color = "red" // color = "blue" // Ошибка! val нельзя переприсвоить /* Правила именования: - буквы, цифры, подчёркивания - начинается с буквы или _ - не ключевое слово - camelCase - переменная должна быть объявлена до использования */
  • var — изменяемая ссылка, можно присваивать новое значение.
  • val — неизменяемая ссылка, аналог final в Java.
  • Kotlin предпочитает val везде, где возможно, для безопасности.
  • Имена чувствительны к регистру, age и Age — разные переменные.
04_strings.kt Строки, экранирование, шаблоны, функции String
Зачем: Показать работу со строками: escape-последовательности, интерполяцию через ${} (и её краткую форму $varName), конкатенацию и встроенные функции (length, uppercase).
println("The answer is \"yes\"") // экранирование кавычек println("Here is a backslash: \\") var cat = "Pip" var cat2 = "Billie" println("My cat's name is ${cat}") // шаблон println("My other cat's name is " + cat2) // конкатенация println("cat length: ${cat.length}") println(cat2.uppercase())
  • Внутри строк двойные кавычки и обратный слеш нужно экранировать: \", \\.
  • ${переменная} — интерполяция; для простой переменной фигурные скобки можно опустить: "$cat".
  • Но если после переменной идёт буква/цифра — {} обязательны: "${cat}s".
  • Строки в Kotlin неизменяемы, но имеют множество полезных методов.

06_data_types.kt Примитивные типы и числа типы
Зачем: Познакомить с числовыми типами Kotlin (Byte, Short, Int, Long, Float, Double), показать автоматический вывод типа и явное указание, а также суффиксы L и F.
var price = 12.99 // Double var amount = 3 // Int val total = price * amount println("Price: ${price}, ${price::class.simpleName}") var dogs: Int = 10 var atoms: Long = 1234566 var molecules = 7890L // Long var price2 = 2.99F // Float
  • Диапазоны: Byte — 8 бит, −128..127; Short — 16 бит, −32768..32767; Int — 32 бита, −2³¹..2³¹−1; Long — 64 бита, −2⁶³..2⁶³−1; Float — 32 бита, ~6–7 значащих цифр; Double — 64 бита, ~15–16 значащих цифр.
  • ::class.simpleName — получение имени типа в читаемом виде (без пакета и JVM-обёрток).
  • Суффиксы L (Long) и F (Float) явно задают тип, иначе компилятор сделает Int или Double.
  • Kotlin не делает неявных преобразований между числами (см. следующий файл).
07_conversions.kt Преобразование типов toLong(), toInt()
Зачем: Показать явные преобразования между числовыми типами и предупредить о возможной потере данных (например, 2.99F.toInt() даёт 2).
val cats = 3 val longCats = cats.toLong() var fl = 2.99F var int = fl.toInt() // 2 — дробная часть отбрасывается
  • Kotlin не делает неявных преобразований между числами (в отличие от Java).
  • Всегда нужно вызывать toXxx() явно: toLong, toInt, toDouble, toFloat, toByte, toShort.
  • При сужении типа возможна потеря точности — это осознанное решение программиста.
  • При расширении типа (Int → Long) потери не происходит.
08_arithmetic_operations.kt Арифметические операции и сложный процент практика
Зачем: Практический пример с банковским вкладом: сложный процент за 5 лет. Демонстрирует оператор *= и работу с Double.
var funds = 1000.00 val interest = 1.055 funds *= interest // funds = funds * interest // ... повторяется 5 раз
  • Составные операторы присваивания: *=, +=, -=, /=, %=.
  • $${funds} — экранирование знака доллара: первый $ выводится как символ, второй — начало интерполяции.

09_logical_operators.kt Логические операторы &&, ||, !
Зачем: Базовое знакомство с логическими операторами И, ИЛИ, НЕ. Показывает таблицы истинности в действии.
val isTrue = true val isFalse = false println("AND: ${isTrue && isFalse}") // false println("OR: ${isTrue || isFalse}") // true println("NOT: ${!isTrue}") // false
  • && — логическое И (ленивое: если первый операнд false, второй не вычисляется).
  • || — логическое ИЛИ (ленивое: если первый true, второй не вычисляется).
  • ! — унарное отрицание.
  • Результат любого логического оператора — Boolean.
10_exercise.kt Упражнение: логические условия для фермы практика
Зачем: Применить логические операторы для вычисления условий получения финансирования. Проверяет понимание приоритета операторов и скобок.
val req1 = numCows <= 5 val req2 = numCowsWithMilk > 0 val req3 = (1 + kids) >= 3 val getsFunding = (req1 && req2) || req3
  • Скобки важны для правильной группировки условий.
  • Операторы сравнения <=, >, >= возвращают Boolean.
  • Без скобок && имеет более высокий приоритет, чем ||.
11_nullability.kt Null safety: ?, ?., ?:, !! null safety
Зачем: Одна из ключевых фич Kotlin — безопасная работа с null. Показаны nullable-типы, безопасные вызовы, Elvis-оператор и оператор «утверждения» !!.
var name: String? = null // nullable // var otherName: String = null // ошибка компиляции var total = num1?.plus(num2) // безопасный вызов var elvis: Int? = num1 ?: 5 // Elvis: 5 если null
  • String? — тип, который может быть null. Без ? присвоить null нельзя.
  • ?. — вызов метода только если объект не null. Результат тоже nullable.
  • ?: — Elvis: вернуть правое значение, если левое null.
  • !! — бросить NPE, если null. Использовать только при полной уверенности.
  • Для nullable-чисел арифметика недоступна напрямую — нужны методы plus, minus и т.д.
12_exceptions.kt Исключения: try/catch/finally и throw exceptions
Зачем: Научить обрабатывать исключения и создавать собственные. Показать блок finally, который выполняется всегда.
try { println(txt.toInt()) } catch (e: Exception) { println("Exception: ${e.message}") } finally { println("finally") } throw Exception("Input is not 123")
  • try — код, который может выбросить исключение.
  • catch — обработка конкретного типа исключения. e.message даёт текст ошибки.
  • finally — выполняется всегда, даже если было исключение или return.
  • throw — явное выбрасывание исключения.
  • Порядок блоков: только try + catch, или try + finally, или все три.
13_lists.kt Списки: listOf и arrayListOf коллекции
Зачем: Познакомить с неизменяемыми списками (listOf) и изменяемыми (arrayListOf). Показать доступ по индексу и основные операции.
val months = listOf("Jan", "Feb", "Mar") println(months[0]) println(months[2]) println(months.get(2)) // то же, что months[2] println(months.indexOf("Feb")) val letters = arrayListOf("a", "b", "c") letters.add("d") letters.remove("a")
  • listOf — неизменяемый список: нельзя добавлять/удалять элементы.
  • arrayListOf — изменяемый, аналог ArrayList в Java.
  • Доступ по индексу: [] или get() — полностью эквивалентны.
  • indexOf возвращает индекс первого вхождения или −1.

val items = arrayListOf("laptop", "mouse", "pen", "paper", "mug", "phone") val removedItems = arrayListOf("pen", "paper", "mug", "phone") items.removeAll(removedItems) println("Remaining Items: ${items}")

15_sets.kt Множества: setOf и hashSetOf коллекции
Зачем: Объяснить, что множество хранит только уникальные элементы. Показать неизменяемый setOf и изменяемый hashSetOf.
val numberSet = setOf(4, 2, 6, 9, 5, 2) // 2 — дубликат println(numberSet) val initSet = setOf<Int>() // пустое множество val hashSet = hashSetOf(1,2,3,4,4,5,6) hashSet.add(10)

17_map.kt Карты: mapOf и hashMapOf коллекции
Зачем: Познакомить с парами «ключ-значение». Неизменяемая mapOf и изменяемая hashMapOf, доступ по ключу через [].
var count = mapOf(1 to "one", 2 to "two", 3 to "three") println(count) var emptyMap = mapOf<Int, String>() var hashMap = hashMapOf<Int, String>() hashMap[4] = "four"
  • to — инфиксная функция создания Pair, удобный синтаксис для Map.

18_exercise.kt Упражнение: посещаемость и null-safe доступ к Map практика
Зачем: Практика HashMap с безопасным извлечением значений через ?. и Elvis-оператор, а также проверка наличия ключа containsKey.
var attendance = hashMapOf("23 Sept" to 2837, "24 Sept" to 3726, "25 Sept" to 6253) attendance["26 Sept"] = 6253 val total: Int = attendance.get("26 Sept")?.plus(attendance.get("25 Sept") ?: 0) ?: 0 println("Attendees for Sept 25-26: $total") println("Sept 22 attendance available?: ${attendance.containsKey("22 Sept")}")
  • get() возвращает nullable-значение, если ключа нет.
  • Цепочка ?. и ?: безопасно обрабатывает отсутствующие ключи.
  • containsKey возвращает Boolean — есть ли ключ в карте.
19_if_exercise.kt Упражнение: if и вложенные условия практика

if (hasEggs) { cost = 12 * eggPrice if (hasBacon) { cost += (2 * baconPrice) } } else println("No eggs!!")

20_when_exercise.kt Упражнение: when по первой букве практика
Зачем: Показать when как мощную замену switch. Проверка по нескольким значениям через запятую.
val firstLetter = name[0].lowercase() when (firstLetter) { "a", "b", "c" -> println("Salutations") "d", "e", "f" -> println("Ello m8") else -> println("Oi!") }

  • Можно объединять несколько значений через запятую.

21_for.kt Циклы for: коллекции и диапазоны циклы
Зачем: Показать два основных вида for: по элементам коллекции и по диапазону 1..3.
val pets = setOf("dog", "cat", "bird") for (p in pets) { println("Hi $p") } for (i in 1 .. 3) { println("Strike $i...") } println("Out!")
  • for (x in collection) — перебор элементов.
  • 1..3 — диапазон, включающий оба конца (1, 2, 3).
  • Дополнительно: until (не включая правый конец), downTo (в обратном порядке), step (шаг).
  • Переменная цикла p / i видна только внутри тела.
22_exercise.kt Упражнение: месяцы и високосный год практика
Зачем: Практика for по Map с деструктуризацией, использование if внутри объявления Map и полного условия високосного года.
val year = 2026 // Високосный: делится на 4, но не на 100, либо делится на 400 val isLeapYear = year % 4 == 0 && (year % 100 != 0 || year % 400 == 0) val months = mapOf<String, Int>( "Jan" to 31, "Feb" to if (isLeapYear) 29 else 28, "Mar" to 31, // ... ) for ((name, days) in months) { println("$name: $days") }
  • if как выражение возвращает значение для Map.
  • Деструктуризация for ((name, days) in months) сразу даёт ключ и значение — удобнее, чем month.key / month.value.
  • Полное условие високосного года: year % 4 == 0 && (year % 100 != 0 || year % 400 == 0).
23_while.kt Цикл while и поиск кратных 7 циклы
Зачем: Показать while на примере случайного числа и вывода чисел, кратных 7. Демонстрирует нестандартный шаг цикла через if.
val bigNumber = (100..500).random() println("Number: $bigNumber") var i = 1 while (i < bigNumber) { if (i % 7 == 0) { println(i) i += 7 } else i++ }
  • while проверяет условие перед каждой итерацией.
  • (100..500).random() — расширение IntRange для получения случайного числа.
  • Нестандартный шаг: когда i кратно 7 — увеличиваем сразу на 7, иначе на 1.
24_functions.kt Функции и вычисление площади круга функции
Зачем: Определение функции с одним выражением, использование глобальной константы и forEach для обработки списка.
val pi = 3.14159 fun getCircleArea(r: Int) = pi * r * r radii.forEach { r: Int -> val area = getCircleArea(r) println("Area for circle of radius $r: $area") }
  • Однострочные функции без блока {} и return.
  • forEach — функция высшего порядка для перебора коллекции (в отличие от map, который возвращает новую коллекцию).
  • pi — свойство верхнего уровня (глобальная константа).
  • Тип возвращаемого значения выводится автоматически (здесь Double).
25_more_functions.kt Перегрузка и vararg функции
Зачем: Показать две важные возможности: перегрузку функций (одинаковое имя с разными параметрами) и переменное число аргументов vararg.
fun multiply(number: Int) = number * 2 fun multiply(number: Int, multiplier: Int) = number * multiplier fun sayHi(vararg names: String) { for (name in names) { println("Hi $name") } }
  • Перегрузка — компилятор выбирает функцию по количеству/типу аргументов.
  • vararg — позволяет передать любое количество аргументов; внутри это массив.
  • У функции может быть только один vararg, обычно он последний.
26_lambdas.kt Лямбды и функции высшего порядка функции
Зачем: Объяснить, что такое лямбда-выражения и как передавать функции как параметры. Это основа функционального стиля в Kotlin.
val lambda = { name: String -> println("Hello $name") } val names = listOf("Thing 1", "Thing 2") sayHello(names, lambda) fun sayHello(names: List<String>, doSomething: (String) -> Unit) { for (name in names) { doSomething(name) } }
  • Лямбда — анонимная функция в фигурных скобках: { параметры -> тело }.
  • (String) -> Unit — тип функции: принимает String, ничего не возвращает.
  • Unit в Kotlin — аналог void в Java.
  • Функции высшего порядка принимают другие функции как аргументы.
27_classes.kt Классы, наследование, open ООП
Зачем: Введение в классы: свойства, методы, наследование. Ключевое слово open для разрешения наследования.
class Car { var model: String? = null var topSpeed: Int = 120 fun start() { println("Started $model") } } open class Dog { ... } class Corgi : Dog() { ... }
  • Классы по умолчанию final — нельзя наследоваться.
  • open снимает это ограничение и позволяет создавать подклассы.
  • Синтаксис наследования: class Corgi : Dog() — скобки означают вызов конструктора родителя.
  • Подкласс Corgi получает все методы Dog и добавляет свой strut.
28_class_concepts.kt Companion, get/set, init, конструкторы ООП
Зачем: Продвинутые возможности классов: companion object (статический контекст), кастомные get/set, блок init, множественные конструкторы.
class Vehicle { companion object { fun getInfo() = "This is a car class" } var topSpeed: Int get() = 100 set(value) { println("Set new top speed: $value") } init { println("Creating vehicle...") } constructor() { ... } constructor(newModel: String) { ... } constructor(newModel: String, newSpeed: Int) { ... } }
  • companion object — аналог статических членов; вызов Vehicle.getInfo() без создания экземпляра.
  • Кастомные get/set позволяют добавить логику при доступе к свойству (здесь get всегда возвращает 100 — демонстрация).
  • init выполняется сразу после создания объекта, до тела основного конструктора.
  • Несколько constructor — перегрузка конструкторов с разными наборами параметров.
29_exercise.kt Упражнение: класс Calculator практика
Зачем: Комплексное упражнение на классы: свойства, методы, работа с Number и приведение типов.
class Calculator { var total: Double = 0.0 fun add(value: Number) { val valDouble = value.toDouble() print("${this.total} + $valDouble = ") this.total += valDouble println(this.total) } // ... subtract, multiply, divide, reset }
  • Number — базовый тип для всех чисел, позволяет принимать Int, Double, Float и т.д.
  • toDouble() — единое приведение к Double для вычислений.
  • this.total — явное обращение к свойству класса.
  • Метод reset обнуляет счётчик.
30_interfaces.kt Интерфейсы и фабрики ООП
Зачем: Показать интерфейсы как контракт, реализацию по умолчанию, переопределение override и паттерн «фабрика» для создания объектов. Класс может реализовать несколько интерфейсов.
interface Oven { var temperature: Int fun turnOn() fun turnOff() fun cook() { println("Cooking at Temperature: $temperature") } } class Samsung: Oven { override var temperature = 500 override fun turnOn() { println("Turning on Samsung") } override fun turnOff() { println("Turning off Samsung") } } fun samsungFactory(): Oven = Samsung()
  • Интерфейс может содержать абстрактные (turnOn, turnOff) и конкретные (cook) методы.
  • Свойство temperature только объявлено — значение задаётся в реализующем классе.
  • override обязателен при реализации членов интерфейса.
  • Фабричная функция возвращает интерфейсный тип, скрывая конкретную реализацию.
31_exercise.kt Упражнение: интерфейс Coffee и случайный выбор практика
Зачем: Практика интерфейсов: два класса реализуют Coffee, фабричная функция случайно выбирает сорт. Метод quench имеет реализацию по умолчанию, но переопределяется в классах.
interface Coffee { var coffeeType: String fun wakeUp() { println("Waking up!") } fun quench() { println("Ahh, thirst quenched!") } } class Arabica: Coffee { override var coffeeType: String = "Arabica" override fun quench() { println("Thirst quenched with $coffeeType") } } fun orderCoffee(): Coffee { val choice = (0..1).random() return if (choice == 1) Arabica() else Robusta() }
  • quench имеет реализацию по умолчанию, но в классах переопределяется — это демонстрация полиморфизма.
  • Фабрика использует random() для случайного выбора сорта.
  • Возвращается тип интерфейса — клиент не знает о конкретном классе.
  • wakeUp() не переопределяется, используется реализация из интерфейса.
32_generics.kt Обобщённый класс Bike<T> generics
Зачем: Введение в обобщения (generics): класс с параметром типа, который может хранить и отображать значение любого типа.
class Bike<T> { fun display(value: T) { println(value.toString()) } } fun main() { val bike = Bike<Int>() bike.display(100) }
  • Bike<T> — параметризованный тип, T — параметр типа.
  • При создании указывается конкретный тип: Bike<Int>.
  • Метод display принимает значение типа T.
  • Generics обеспечивают типобезопасность и переиспользование кода.
